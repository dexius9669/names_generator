# Генератор имён — магирианский стиль

Standalone HTML-генератор имён для НРИ и варгеймов: слоги и титулы по таблицам
из статьи «Random names: Magira style» (Zenopus Archives / Boggswood). Вся
логика — в JS внутри страницы, без бэкенда и внешних зависимостей. Открывается
локально и без интернета.

Открыть: https://dexius9669.github.io/names_generator/

## Что внутри

- `names_generator.html` — самодостаточный генератор:
  - d100 на число слогов (01–10 — один, 11–70 — два, 71–90 — три, 91–100 — четыре);
  - каждый слог — отдельный d100 по таблице из 100 строк (повторы `Gi` и `Ra`
    сохранены как отдельные строки и потому выпадают вдвое чаще);
  - запись слитно / через пробел / через дефис, необязательный апостроф между
    гласными (`Ma’ag`);
  - удвоение последней буквы у односложных имён (`Gadd`);
  - титул по d20 (или выбранная строка таблицы), включая порядковые
    `the First … the Twentieth`;
  - пакетная генерация до 20 имён, копирование, разбивка бросков у каждого имени
    (чтобы повторить результат физическими кубиками), история последних 50 имён;
  - настройки и история хранятся в `localStorage`.
- `index.html` — редирект на генератор для корня сайта.
- `names_gen_rules.txt` — исходные правила и таблицы.

## Атрибуция

Таблицы слогов и титулов — из статьи
[«Random names: Magira style»](http://boggswood.blogspot.com/2013/09/random-names-magira-style.html)
(2013), со ссылкой на Zenopus Archives.
